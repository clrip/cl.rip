Using it

  1. 1Copy a link to any catalog item, or just its ID number.
  2. 2Paste it above and press Extract.
  3. 3Download the PNG, or strip the guides first.

How it works

  • It pulls an ID out of whatever you paste. A full URL or a bare number both work.
  • It asks Roblox where that asset lives.
  • Shirts and pants come back as XML, not an image. The XML points at a second asset holding the real 585x559 texture, so it goes and fetches that one too. A T-shirt is already the image.
  • It redraws the texture on a canvas in your browser so you can save it.

Why it exists

Roblox never shows you a template flat. You only ever see it wrapped on a 3D avatar. A web page can't go and fetch the files itself either, because the asset endpoints send no CORS headers, so a small Cloudflare Worker passes them through.

Re-uploading someone else's artwork as your own breaks Roblox's terms. This is a reference tool, not a way around that.
